### 一、核心操作环境搭建  

在CTF Web安全竞赛中，搭建稳定且高效的操作环境是成功的第一步。推荐使用**VMware**虚拟化平台配合**Kali Linux**渗透测试系统。  
注：后面的一些软件安装很多都基于这两个平台  

#### 环境搭建步骤：  h

1. **安装VMware虚拟化平台**  

   - 下载并安装最新版本的VMware Workstation或VMware Player  

   - 确保系统满足虚拟化技术要求（Intel VT-x或AMD-V）  

2. **部署Kali Linux系统**  

   - 下载Kali Linux镜像文件（建议使用最新稳定版）  

   - 在VMware中创建新的虚拟机  

   - 配置合适的硬件资源（建议至少2GB内存和20GB硬盘空间）  

3. **系统优化**
   - 更新系统软件包：`sudo apt update && sudo apt upgrade`  

   - 安装必要的渗透测试工具集

### 二、Web渗透基础工具  

#### 1. Dirsearch目录爆破工具  

**Dirsearch**是一款基于Python的高级命令行工具，专门用于暴力破解Web服务器上的隐藏目录和文件，是寻找后台或敏感泄露文件的利器。  

**Kali快速安装命令：**  

```bash
sudo su
apt-get update
apt-get install dirsearch
```  

**常用指令：**  

```bash
# 基本使用
dirsearch -u <URL>
# 指定扩展名
dirsearch -u http://target.com -e php,html,txt
# 自定义字典
dirsearch -u http://target.com -w /path/to/wordlist.txt
# 递归扫描
dirsearch -u http://target.com -r
```  

**拓展知识：**  

- Dirsearch支持多线程扫描，可通过`-t`参数调整线程数  

- 支持代理设置，适用于需要通过代理扫描的场景  

- 可导出扫描结果为多种格式（JSON、XML等）  

#### 2. GitHack源码还原脚本  

**GitHack**是一个.git泄露利用脚本，当网站存在配置不当时导致文件夹暴露，它可以有效重建并还原工程的源代码。
**工具获取：**  

```bash
git clone https://github.com/liajiejie/GitHack.git
cd GitHack
```  

**基本命令格式：**  

```bash
python2 GitHack.py http://目标网址/.git/
```  

**使用技巧：**
- 确保目标网站确实存在.git泄露  

- 扫描结果会生成以目标域名命名的文件夹  

- 适用于代码审计和漏洞分析  

#### 3. 中国蚁剑(AntSword) Webshell管理工具  

**中国蚁剑(AntSword)**是一款开源的跨平台网站管理工具，常用于在成功获取目标服务器Webshell权限后，提供友好的文件管理、终端执行和数据库操作界面。  

**官方下载地址：**
- [https://github.com/AntSwordProject/](https://github.com/AntSwordProject/)  

**安装步骤：**
1. 下载两个部分：加载器和项目核心源码  

2. 解压后，打开加载器的文件夹  

3. 双击"AntSword.exe"启动程序  

4. 初始化并选择解压好的核心源代码文件夹  

5. 再次打开加载器即可正常使用  

**加载器版本选择：**  

- 根据操作系统选择合适的版本（Windows、Linux、macOS）
- 确保版本兼容性以获得最佳体验
