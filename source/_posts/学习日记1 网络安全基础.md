## 一、 网络安全简介  


**定义**（不完全严谨版本）：

广义的网络安全即网络空间安全，网络空间由设施与网络组成。

狭义的是指采取必要措施防范外部对网络的各种攻击破坏，保障网络中的信息与数据。

**发展历史**：  

 通信安全时期 > 信息安全时期 > 信息保障时期 > 网络空间安全时期  

    1              2             3               4

时期1仅限于保证信息的物理安全以及通过密码解决保密问题；  

时期2主要确保信息的完整性、可用性、保密性；  

时期3新增了可控性与不可否认性两个原则，且从业务，安全体系，管理三方面构建企业信息保障体系；  

时期4扩大了信息安全的内涵与外延。

## 二、操作系统

**操作系统简介**：
管理计算机硬件与软件资源的程序。在网安视角下，OS 提供各种接口（端口、进程、服务），这些接口是受到攻击的切入点。

主要分为桌面级（Windows/macOS，易上手）和服务器级（Linux/Unix，稳定性高，绝大多数黑客攻击目标）。

#### 基础导航与文件操作

#### 电脑系统查询

**ver**：查当前 Windows 的版本号。  
    
具体应用{
    根据版本号去查询是否存在已知的、针对该版本的**公开漏洞**
}  

**hostname**：查这台电脑的名字。  
  
 具体应用{
    名称可能包含“<abbr title="Domain Controller：域控制器，负责管理网络中的用户账户、身份验证和安全策略。攻击者往往将其作为首要目标。">DC</abbr>”（域控制器）、“<abbr title="Database Server：数据库服务器，存储核心业务数据。攻击者获取权限后可能进行拖库或提权。">SQL</abbr> ”（数据库服务器）等敏感信息，能帮助攻击者判断其 **重要性**
}  

**date / time**：查看或修改当前系统的日期和时间。  
  
具体应用{
    攻击者可能修改时间去干扰日志记录(时间戳伪造与反取证)  
    攻击者可利用时间调试攻击Kerberos 等认证协议(<abbr title="Kerberos 等认证协议依赖时间同步，时间偏差过大将认证失效；攻击者可利用时间调试攻击。">计时攻击</abbr> )  
    电脑收到入侵时,第一时间核查系统时间是否异常.
}  
⚠️ 注意：修改系统时间是高权限操作。

**getmac**：查看电脑网卡的物理地址（<abbr title="网卡的硬件物理地址，出厂固化，局域网内可以唯一标识一台设备。">MAC 地址</abbr> ）。  
  
具体应用{
    攻击者可以读取MAC地址进行标记,后续可以再次定位(设备指纹标记)
    获取<abbr title="网卡的硬件物理地址，出厂固化，局域网内可以唯一标识一台设备。">MAC 地址</abbr> 是进行ARP欺骗的必备条件[ARP欺骗是内网经典攻击,具体介绍不在此叙述]
    防护者可记录恶意设备的MAC地址进行防御处理.
}   


#### 网络基础侦测

**ping 网站或IP**：测试网络通不通，看有没有延迟。
  
具体应用{
    假设拿到了一个内网机器的权限，可编写脚本扫描全部主机，看有哪些机器开机。

}

**ping 8.8.8.8 -t**：持续不断地去 Ping 目标。  
  
具体应用{
    使用 `ping 8.8.8.8 -t` 持续发包，排除网卡或网线接触不良干扰，确认目标到底是不通，还是单纯屏蔽了ICMP协议（禁Ping）。
}

**tracert 网站或IP**：路由追踪。
即可以看发出去的数据包经过了哪几台路由器才找到目标的。  
  
具体应用{
    通过对目标域名或IP执行路由追踪，判断目标是否经过<mark>CDN加速节点</mark>，跳过这些节点找到陌生的源站服务器，从而进行攻击。
    排查路由节点中是否存在商业WAF防护（如阿里云盾、Cloudflare等 相当于防火墙），可绕过这些再进行攻击。
}

**nslookup 网址**：查域名的 IP 地址（DNS解析）。  
  
具体应用{  

通过查询NS记录|即找出负责解析域名的DNS服务器在哪个IP地址|和尝试发口令找到漏洞（如`ls -d 目标域名.com`  这个口令），批量获取大量的平时不开放网址。  

如果上面的方法失败了，可以使用一种朴实无华的手法，盲猜，即将常见名字的站点名字挨个发过去询问总机，看是否存在。  
可发现如 `admin.xxx.com` 或 `test.xxx.com` 等防护薄弱的内部测试后台入口。
}

#### 进阶检测命令

**ipconfig /all**：查看完整网络配置。判断当前是否在域内、有没有多网卡、DNS 服务器配置等。  
  
具体应用{
    判断是否处于域环境：查看“主 DNS 后缀”是否包含 `corp`、`ad`、`local` 等常见域控关键词，以此判断目标主机是否处于域环境，为后续内网横向移动做准备。
    探测隐藏网卡与虚拟机：排查是否存在 `VMnet`、`VirtualBox` 等虚拟网卡，判断这台主机是一台真实物理机还是云虚拟机（云主机可能带有特殊的网络特征）。
    定位 DNS 服务器：查看本机配置的 DNS 服务器是内网 IP 还是公网 IP，辅助判断是否疑似处于域环境，也方便判断接下来在渗透过程中是否存在 DNS 劫持的情况。
}

**netstat -ano**：**极高频使用**。查看本机所有活动的 TCP/UDP 连接及对应的 PID。常用于查找后门连接、异常端口监听（如反向 Shell）。  

具体应用{
    挖出 C2 恶意通信：攻击者拿到权限后，用此命令查看是否存在与境外 IP、非正常端口建立的 `ESTABLISHED`（已连接）状态，疑似回连到攻击方 C2 服务器的恶意连接。
    找出异常监听后门：查看是否有异常端口处于 `LISTENING` 监听状态（如 4444、5555、8080 等非业务端口），结合 PID 反向定位是什么程序在监听，揪出攻击者留下的持久化后门。
    定位反向 Shell：如果发现一个陌生的 PID 正在监听本地端口，且处于 `ESTABLISHED` 状态，那极大概率是攻击者植入的反弹 Shell 连接。
}


**arp -a**：查看 ARP 缓存表。内网渗透中，可用于探测存活主机或检测 ARP 欺骗攻击。  
  
具体应用{
    内网存活主机探测：在没有端口扫描工具（如 Nmap）时，直接查看本机 ARP 缓存表，里面记录了近期与本机发生过通信的内网 IP，能快速判断同网段有哪些机器存活。
    ARP 欺骗攻击检测：如果在 ARP 缓存表里发现同一个 IP 绑定了两个不同的 <abbr title="网卡的硬件物理地址，出厂固化，局域网内可以唯一标识一台设备。">MAC 地址</abbr>，说明当前局域网内极有可能存在 ARP 欺骗攻击（攻击者正在拦截和嗅探流量）。
    设备指纹识别：根据 MAC 地址的前缀（OUI）快速识别设备厂商（如华为、华三、Apple、Dell），辅助判断目标主机的物理类型（是电脑还是打印机或者 IoT 设备）。
}

**systeminfo**：必用命令。获取操作系统版本、安装日期和已安装补丁列表（KB号）。知道补丁情况，就能快速判断这台机器可能对哪些漏洞（如 MS17-010）免疫。  
  
具体应用{
    快速锁定提权 EXP：攻入一台主机后，通过列出的 `<abbr title="微软发布的补丁包编号，如MS17-010对应永恒之蓝漏洞补丁。">KB 补丁号</abbr>`，去漏洞库比对。如果缺失某个关键 KB 补丁，可以直接确定可利用的提权漏洞，避免做无用功。
    发现安全防御工具的痕迹：部分杀毒软件或主机安全软件（HIDS）会在系统信息里留下特定服务特征，结合 `systeminfo` 和 `tasklist`，可以评估当前环境下杀软的威胁度。
    推测机器运维习惯：查看“系统安装日期”和“开机时间”，判断这台服务器是长期不关机的核心业务机，还是常重启的测试机，从而影响攻击时间窗口的选择。
}

**whoami**：查看当前用户身份。提权第一句，判断是普通用户还是 SYSTEM。
  
  具体应用{
 假设你是攻击者，刚刚你通过漏洞潜进一台电脑，这个是你第一个输入的命令，帮助你查询自己的权限有多高。   

若返回 `nt authority\system` 或 `root`，说明开局即巅峰，无需提权；  
若返回普通用户，立刻转入本地提权阶段。  

如果返回 Administrator ，说明 你当前独掌大权，可以任意发口令。  
如果返回 <abbr title="域，指大型企业网络环境下，由域控制器集中管理所有电脑的架构。">DOMAIN</abbr>\aaa ，说明 你属于域内的普通用户，相当于你的电脑属于公司，由“域控”总部统一管理。

然后输入口令  whoami /priv  ，  
如果有  SeImpersonatePrivilege  出现，你可以用 “烂土豆” 这个现成提权工具，进行提升权限的操作。
}

### 2. 用户与组管理

图形工具：运行 lusrmgr.msc，可以看到所有的“本地用户和组”。

安全核心：在 Windows 中，有两个极其重要的隐藏用户：Administrator（超级管理员，目标就是拿下它）和 Guest（默认停用的访客）。如果你去渗透测试，第一步就是看有没有把 Guest 账户激活并提权到管理员组的操作痕迹。

### 3. 进程与软件管理

图形工具：Ctrl+Shift+Esc 打开任务管理器。

网安陷阱：攻击者常常伪装成系统进程（如 svchost.exe）。你需要学习如何查看进程的具体路径（右键->打开文件所在位置）。如果一个 svchost.exe 在 C:\Windows\Temp 下面，那绝对是病毒。

### 4. Windows 防火墙

简单理解：它是一个“守门的保安”。

实操：你在打靶机或者做内网渗透时，发现 3389（RDP远程桌面）连不上，90% 是因为防火墙没开 3389 端口。你能用 wf.msc 或者命令行 netsh advfirewall firewall 去手动添加入站规则。

### 5. RDP 远程桌面

协议端口：默认是 3389。

网安要点：这是黑客在拿下 Windows 服务器后最常做的事——开启 RDP 服务，给自己创建一个隐藏的管理员账号，然后通过 3389 端口远程登录，像操作自己的电脑一样操作受害服务器。知道 RDP 也是防护的第一步，平时不用建议直接禁用 3389。
