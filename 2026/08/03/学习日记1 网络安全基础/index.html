一、 网络安全简介

定义（不完全严谨版本）：

广义的网络安全即网络空间安全，网络空间由设施与网络组成。

狭义的是指采取必要措施防范外部对网络的各种攻击破坏，保障网络中的信息与数据。

发展历史：

通信安全时期 > 信息安全时期 > 信息保障时期 > 网络空间安全时期 1 2 3 4

时期1仅限于保证信息的物理安全以及通过密码解决保密问题； 时期2主要确保信息的完整性、可用性、保密性； 时期3新增了可控性与不可否认性两个原则，且从业务，安全体系，管理三方面构建企业信息保障体系； 时期4扩大了信息安全的内涵与外延。

重大事件

📅 1988年：[Morris 蠕虫] 首个网络蠕虫，开启互联网安全纪元。 📅 1999年：[CIH 病毒] 首个破坏硬件BIOS的病毒。 📅 2000年：[爱虫病毒] 全球邮件风暴，损失巨大。 📅 2003年：[SQL Slammer] 极短时间内瘫痪全球网络。

--- (2000s 中后期 安全沉淀) ---

📅 2011年：[RSA SecurID] 安全令牌数据失窃。 📅 2013年：[棱镜门 PRISM] 全球隐私监听曝光 / [Target] 支付系统入侵。 📅 2014年：[Heartbleed] 互联网“心脏出血”漏洞。 📅 2017年：[WannaCry] 勒索病毒全球爆发 / [Equifax] 征信巨头泄露 / [NotPetya] 擦除器攻击。 📅 2020年：[SolarWinds] 供应链攻击曝光。 📅 2021年：[Colonial Pipeline] 关键基础设施勒索断供 / [Log4Shell] 十年来最严重漏洞。 📅 2024年：[XZ Utils] 开源软件供应链后门。

证书与赛事

证书：CISSP、CISA、CISP、CCSP、CCNA Security、网络工程师相关证书 赛事：CTF、XCTF、全国大学生网络安全竞赛、ISC2024、SCTF

网络安全意识与法律法规

<安全意识>

密码管理、社工防范、钓鱼邮件识别、移动办公安全、USB 安全 企业员工常见风险：弱口令、未经授权软件、外部链接点击

<主要法律法规>

《中华人民共和国网络安全法》《数据安全法》《个人信息保护法》 《关键信息基础设施安全保护条例》 等保2.0：信息安全等级保护制度

二、操作系统

操作系统简介： 管理计算机硬件与软件资源的程序。在网安视角下，OS 提供各种接口（端口、进程、服务），这些接口是受到攻击的切入点。

主要分为桌面级（Windows/macOS，易上手）和服务器级（Linux/Unix，稳定性高，绝大多数黑客攻击目标）。

Windows 系统 {

###1. 常用命令（基础知识排查工具）

               可用 CMD 或 PowerShell 运行
              可用win+R打开运行窗口，输入cmd打开

####基础导航与文件操作

dir：列出当前文件夹里的所有内容。

cd 目录名：进入指定文件夹。

md 新文件夹名：创建一个新的文件夹。

type 文件名.txt：直接在命令行里查看文本文件的内容。

copy 原文件 目标路径：复制文件。

move 原文件 目标路径：剪切（移动）文件。

del 文件名：删除文件。

####{}电脑系统查询

ver：查当前 Windows 的版本号。

hostname：查这台电脑的名字。

date / time：查看或修改当前系统的日期和时间。

getmac：查看电脑网卡的物理地址（MAC地址）。

####{}网络基础侦测

ping 网站或IP：测试网络通不通，看有没有延迟。 可以用它来扫描内网有多少台机器开机了

ping 8.8.8.8 -t：持续不断地去 Ping 目标。

tracert 网站或IP：路由追踪。 即可以看发出去的数据包经过了哪几台路由器才找到目标的。（排查网络故障点非常好用）。

nslookup 网址：查域名的 IP 地址（DNS解析）。

####{}进阶检测命令

ipconfig /all：查看完整网络配置。判断当前是否在域内、有没有多网卡、DNS 服务器配置等。

netstat -ano：极高频使用。查看本机所有活动的 TCP/UDP 连接及对应的 PID。常用于查找后门连接、异常端口监听（如反向 Shell）。

nslookup：DNS 解析验证。常用于探测内网 DNS 服务器，或判断是否存在 DNS 劫持。

arp -a：查看 ARP 缓存表。内网渗透中，可用于探测存活主机或检测 ARP 欺骗攻击。

systeminfo：必用命令。获取操作系统版本、安装日期和已安装补丁列表（KB号）。知道补丁情况，就能快速判断这台机器可能对哪些漏洞（如 MS17-010）免疫。

whoami：查看当前用户身份。提权第一句，判断是普通用户还是 SYSTEM。
